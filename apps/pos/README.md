# Testyco POS

Flutter mobile/tablet: login, toko, katalog, tampilan stok utuh/terbuka/siap/karantina/susut beserta revisi, pesanan dan rincian pengiriman melalui API. Aksi operasional saat ini melalui web; checkout/shift/offline belum tersedia. Registry fitur pada lib/main.dart, design system pada lib/design_system. Lihat README root untuk SDK, flag dan validasi perangkat.
