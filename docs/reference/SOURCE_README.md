- Folder Markdown berisi 15 file teks terstruktur untuk agent atau programmer.

- Mulai dari BACA_DULU_Indeks_Dokumen, kemudian 00_BRD_Bisnis_Dimsum, lalu PRD_01 hingga PRD_13 sesuai kebutuhan.
- Status usulan dan keputusan yang belum disepakati tetap berlaku.
