# Riwayat pergerakan stok web

Irisan PRD 05-MOV memakai endpoint ledger yang sama dengan [Flutter](native-stock-ledger.md). Petugas berwenang membuka **Pesanan dan stok toko → Riwayat pergerakan stok**, atau **Riwayat batch ini** dari kartu batch. Halaman baru berada di `/app/stores/{store}/inventory/ledger`, dalam provider Operations web. Tautan merupakan hint dari can_manage_stock; API tetap memeriksa role/assignment/toko pada setiap request.

Pengelola/petugas gudang berwenang mengikuti aturan staff ledger yang sudah ada. Kasir ditolak; admin pusat tidak otomatis boleh melihat ledger mitra tanpa keanggotaan/assignment yang sesuai. Riwayat toko nonaktif tetap dapat dibaca bila organisasi dan akses masih memenuhi syarat. Ini fitur baca, bukan persetujuan transaksi atau penyesuaian stok.

Pilih periode kalender WIB awal/akhir inklusif, maksimal 31 hari, serta pencarian SKU/nama/batch, ID batch persis, sumber dan bucket. Tanggal yang tidak diberikan default hari ini Asia/Jakarta. Pencarian mengikuti perilaku LIKE endpoint yang sudah ada; batch harus milik toko yang diminta atau API mengembalikan 404. **Lihat semua batch** menghapus pembatasan batch sambil mempertahankan periode/filter lain dan kembali ke halaman pertama.

Terapkan filter memulai halaman 1. Pagination maksimal 100 baris mempertahankan filter aktif yang dinormalisasi, bukan isian browser yang belum diterapkan atau old input dari form lain. BFF mengubah kalender WIB menjadi ISO bertimezone `[from,to)`. Konversi yang sama kini dipakai audit, laporan tunai dan ledger melalui `Shared/Application/WibPeriod`, agar aturan batas tanggal tidak berbeda. Tidak ada perubahan periode/definisi omzet laporan.

Kartu menampilkan SKU/nama/kode batch/kondisi/isi kemasan historis, delta bertanda dalam biji, bucket, sumber, pelaku, catatan dan waktu WIB dari occurred_at UTC eksplisit. Contoh +16 biji Karantina tetap pergerakan 16 biji, bukan saldo batch atau bukti 16 kemasan. Metadata berasal snapshot batch API; tidak mengambil harga/konversi master sekarang. Tidak ada running balance, agregasi saldo dari subset, nilai rupiah, atau otomatisasi kelayakan pangan/kedaluwarsa.

Referensi sumber adalah ID asal ledger (misalnya shipment line, process, count atau sale allocation), bukan operation UUID dan bukan selalu ID order/struk. Halaman tidak membuat deep-link ke objek lain atau memberi izin tambahan dari ID tersebut. Waktu diamati adalah waktu pembacaan API; pagination live bukan snapshot beku lintas request.

BFF memakai path toko dari route dan whitelist query. ID toko/organisasi, URL, token atau field lain dari browser tidak diteruskan ke API. Envelope serta setiap store_id row diperiksa; saat batch dipilih, inventory_batch_id juga harus cocok sebelum render. Pagination dibuat di web sendiri tanpa mengikuti next_page_url API. Bearer tetap di session server, cookie/header API tidak disalin ke browser dan respons berhasil private/no-store. Semua metadata/catatan di-escape oleh Blade; referensi ditampilkan sebagai teks.

Denied/401/koneksi gagal/503/wrong-scope bukan riwayat kosong. 401 menghapus session web; 404 batch asing tetap ditampilkan sebagai kegagalan akses objek. Tidak ada query DB API dari web, POST ledger, penulisan audit, stok/kas, ekspor, perubahan schema, dependensi atau aturan finansial baru. Komponen molekul stock-movement menyajikan snapshot/delta, dan halaman menyusun filter/scope/pagination. CSS membungkus teks panjang tanpa JavaScript baru.

Validasi meliputi akses/expiry, whitelist/no-store/token-cookie boundary, kalender WIB, pagination batch/source/bucket/search, signed pieces dan snapshot historis tanpa harga, HTML escaping, batch/store mismatch dan 404, empty/inactive versus connection failure, serta hint navigasi staff/cashier. Tes audit dan laporan juga memeriksa regresi pemakaian WibPeriod bersama. Smoke HTTP terisolasi menampilkan +16 biji karantina dari batch historis isi 8 dan menolak sesi web kasir; tidak mengubah data development. Ini pengujian server/HTML, bukan validasi visual/interaksi browser nyata; browser mobile/tablet, UAT dan PostgreSQL/concurrency belum diverifikasi.
